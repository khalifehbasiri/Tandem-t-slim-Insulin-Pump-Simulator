# Repository scope and publication boundary

This repository is a public portfolio showcase for a private team course project.

## Included

- A recruiter-facing project overview
- Individual and team contribution attribution
- Public demo-video links and their thumbnails
- Team-produced UML and sequence-diagram images
- High-level architecture and verification summaries

## Intentionally excluded

- C++ headers and implementation files
- Qt forms, resource files, and build configuration
- Generated Doxygen source listings
- SQLite databases or sample records
- Course handouts, marking material, full use cases, and the complete traceability matrix
- Credentials, local paths, binaries, and build artifacts

## Why the source remains private

The original repository is a four-person Carleton University course project. Publishing a copied implementation could expose assignment solutions and redistribute teammates' work without the necessary permissions. A source-free showcase preserves the ability to discuss the engineering work while respecting those boundaries.

## Reuse and access

No permission to copy, modify, redistribute, or reuse the underlying private source code is granted by this showcase. Recruiters or interviewers can review the public demonstrations and design material, and Khalifeh Basiri can discuss his individual work at an architectural level.
